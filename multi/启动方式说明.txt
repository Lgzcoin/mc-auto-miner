自动采矿助手 · 多开工具 使用说明
==================================================

一、怎么启动
  双击“启动多开.bat”。它会在同一个窗口里做两件事：
  1) 先弹“矿工设置”面板 → 按回车直接开 3 个客户端
  2) 客户端起来后自动进入“机器人控制台”，实时显示每个号在干嘛
  关掉窗口 = 控制台关掉，机器人继续跑；要再看就再双击一次（不会重复开号）。

二、启动面板里直接改名字、改矿种（不用改文件）
  面板长这样：
      ╭────────────── 矿工设置 ──────────────╮
      1) Miner1   钻(diamond)、绿(emerald)
      2) Miner2   煤(coal)、铁(iron)
      3) Miner3   红石(redstone)、青金(lapis)
      ╰──────────────────────────────────────╯
      数字 = 改这个号（改名 / 改挖什么）   n = 新增一个号   d = 删除一个号
      b = 设基地/矿点 + 存矿箱   i = 设进服指令（如 /home）
      a = 全部重设   r = 改掉线重连间隔（默认 10 秒）   回车 = 直接启动

  ・输数字 1/2/3 → 先问“新名字”，再问“挖什么”
      - 名字：3–16 位英文/数字/下划线。服务器不收中文名，中文会被自动换成 MinerN
      - 改名会连游戏目录一起改（bots\Miner1 → bots\新名字），存档、配置、箱子坐标都跟着走
      - 挖什么：可以写中文，例如“钻石, 绿宝石”“煤 铁”“红石、青金石”；留空 = 不改
  ・输 r → 改掉线后多久重连一次（3–600 秒，默认 10 秒），所有号共用
  ・输 a → 三个号挨个重设
  ・直接回车 → 按当前设置启动
  改完会自动写回 矿工配置.txt，下次启动还是这套。

三、开荒：新号第一次怎么弄（1.9.8 起）
  目标流程：进服 → 登录 → 发指令 → 走到基地 → 开挖 → 挖满回箱。

  1) 站在基地里看坐标（F3），或进游戏后站好位置输 /am base 让它记住当前位置
  2) 启动面板按 b → 选号 → 输基地坐标 x y z → 再输存矿箱坐标（回车=跟基地同一个）
  3) 想让它进服先发指令（回家、领装备等），按 i 输入，多条用 | 隔开：
         /home base | /kit starter
     没有传送权限就留空，它会用寻路自己走过去（远距离很慢，建议先传到基地附近）
  4) 满配镐子、食物、火把提前放进基地箱子；目前“从箱子自动取装备”还没做，
     需要手动把镐子放进它背包一次（下一步可以做自动取货）
  5) 启动后它会：进服 → 自动登录 → 发这些指令 → 寻路到基地点 → 到了才开挖
     → 攒够就回“基地箱”存矿

四、加号 / 删号
  ・n：输一个 3–16 位英文名 → 自动建 bots\新名字 目录，接着问挖什么（可留空，留空就沿用主号配置）
  ・d：输编号或名字 → 再输 y 确认 → 目录整个挪进 bots\_旧目录\名字_删除_时间，
    存档、箱子都不丢，想恢复搬回来就行；正在跑的号会拒绝删，先在它窗口里关游戏
  ・至少保留 1 个号

四、矿工配置.txt（想手改也行）
  密码 = abc123
  重连秒数 = 10
  Miner1 = diamond, emerald
  Miner2 = coal, iron
  Miner3 = redstone, lapis
  只写名字不写矿种（例如 `Miner4 =`）= 这个号沿用游戏里已有配置，不会被覆盖。
  `重连秒数 = 10` = 掉线后每 10 秒重连一次；想改就改这个数字（3–600）。
  支持中文矿名：煤/铁/铜/金/红石/青金石/钻石/绿宝石/石英/紫水晶。
  文件存成 UTF-8 或 ANSI 都能读。

五、控制台能看到什么
    名字      画面                维度   位置            血食  在干什么     登录   攒满   心跳
    Miner1    断开：当前IP在…     未进服 -               -     试7次进服    未登录 -      2 s
    Miner2    游戏世界            主世界 -137,82,448     20/17 挖矿中(钻石) 已登录 未满   1 s
  ・画面 = 它屏幕上正显示什么（游戏世界 / 标题界面 / 登录菜单 / 断开原因）
  ・在干什么 = 自动采矿现在做的事（挖矿中 / 赶路 / 存矿 / 收尾）
  ・登录 = 已登录 / 未登录 / 未发送；攒满 = 攒到多少回箱；心跳 = 状态文件几秒前更新
  ・颜色：绿=挖矿中 青=赶路 紫=存矿 黄=没登录或断线 红=卡住（15 秒没动静）
  ・每约 15 秒还会自己播一行「看板 名字 画面=… 位置=…」，画面变了才播

六、控制台指令
  status / 状态 / 面板   立刻刷一遍状态表
  chat on | chat off     开关聊天显示
  logs 名字              看这个号的历史日志（例如 logs Miner1）
  help                   看全部指令
  quit                   退出控制台（机器人不受影响）

七、几个已知情况
  ・同一 IP 最多 2 个号在线（服务器限制）。第 3 个号会一直提示“当前ip在线玩家已达上限”，
    要么只开 2 个，要么给第 3 个号换出口 IP（手机热点 / 代理）。
  ・界面显示「Game Menu」说明这个号开着 ESC 菜单，挖矿会暂停，回游戏里按 ESC 关掉。
  ・密码三个号都是 abc123；首次没注册的号，进服后模组会先 /reg 再自动补 /login。

八、文件在哪
  游戏目录是 C:\Users\lingo\AppData\Roaming\.minecraft（已关版本隔离）
  每个号的数据：.minecraft\bots\<名字>\
  单号配置：.minecraft\bots\<名字>\config\autominer.json（想精细调箱子坐标就改这个）
  模组：.minecraft\mods\autominer-1.9.8.jar

--------------------------------------------------
九、自己也能测（不用真进服）
  在 multi 文件夹里按住 Shift 右键 → “在此处打开 PowerShell 窗口”，执行：
    powershell -ExecutionPolicy Bypass -File .\控制台.ps1 -SelfTest 5
  它连续刷新 5 秒，最后一行出现“结束，没有异常”就说明界面、读状态、聊天显示都正常。

十、几个常见提示怎么理解
  ・“进服后不会开挖” → 这个号没写矿种；回启动面板输数字重设矿种即可
  ・“只站着不开挖（界面里重设矿种即可打开）” → 这个号的自动开挖开关是关的，重设矿种会顺带打开
  ・“已更新模组：autominer-1.9.8.jar / 已移走旧版：autominer-1.9.6.jar” → 启动器自动升级了，正常
  ・红字“旧版模组被占用 / 旧版挪不动” → 还有客户端开着，把所有游戏窗口关掉再双击启动
  ・状态表整行变红 + 心跳秒数 >15 → 这个号卡住了（多半是断线或界面开在菜单里），看它窗口
  ・心跳/状态每 1 秒刷新一次，图个一眼看清；命令行输入不受影响

十一、图形登录界面能自动点了（1.9.9）
  进服后弹的是“箱子/物品栏”样式的登录菜单时，它现在会自己找带
  “登录 / 登入 / 登陆 / 进入 / 确认 / 密码 / Login”字样的格子点上去，
  点完自动收尾；如果点出来是铁砧输入框，会自动把密码填好并提交。
  不用再手工挑格子。真遇到怪菜单：
    游戏里输 /am gui dump       看这个菜单里有哪些格子
    游戏里输 /am gui set 登录 -1 abc123   （-1 = 自动挑，写 0/3 就是写死那格）
    游戏里输 /am gui kw 登录,进入,确认     改“自动认哪些字”
  唯一点不了的情况：登录界面要求你在告示牌/书里手打文字（不是点格子），
  这种必须你手点一次，模组模拟不了键盘输入。

--------------------------------------------------
十二、不开游戏窗口也能看它们在干嘛（新版控制台）
  · 进控制台就有状态表：每个号「界面 / 维度 / 坐标 / 血饱 / 状态 / 登录 / 回箱 / 心跳」
    界面就是它屏幕上正显示的东西，例如「游戏世界」「标题界面」「断开「连接已丢失」」「「登录菜单」」
  · 自动播报 watch（默认开）：每隔约 15 秒，只要画面或状态变了就说一句
       看板 Miner1  画面=「登录」菜单  位置=-137,82,448  20/18 挖矿中(钻石)  已登录
  · 想细看某个号：输 detail 名字（或 详情 名字）
      画面上、位置、在做、登录状态，外加最近 4 条聊天 + 最近动作/提示
      自动点登录成没成，这里能直接看到「已点击登录菜单第 3 格」
  · watch off / watch on 关掉或打开自动播报；status（面板）随时重画整张表
  · 心跳列超过 15 秒没更新 + 整行变红 = 这个号卡住了，看 detail 里的最后几行动作

十三、自动回收：镐子快坏、背包快满，自己回箱换镐（1.10.0）
  以前只能按时间或攒够钻石回箱。现在多两个触发条件：
  · 身上最好的镐子剩不到 15% 耐久 → 回箱
  · 背包空位只剩 1 格 → 回箱
  回箱存完矿，会自动从打开的箱子里翻一把镐（名字里带 pickaxe 的都认），
  拿到后把快捷栏切到耐久最好的那一把，再回去挖。

  前提：箱子里要有备用镐，不然只会提醒「箱子里没找到备用镐」接着挖。
  想改阈值，游戏里直接敲：
      /am recycle            看现在的设置
      /am recycle on|off     开关
      /am recycle pick 20    镐子剩 20% 就回箱（0 = 关）
      /am recycle slots 2    背包剩 2 格就回箱（0 = 关）
  控制台里的 detail 现在会多一行「镐子耐久：12%  背包空位：3」，低于 15% 变黄。

十四、一键更新（不用再手动换文件）
  双击 一键更新.bat：
  · 先检查 GitHub 上有没有新版本，告诉你 本机 vX → 最新 vY
  · 按 y 才动手：先备份（_备份_日期时间），再替换两个 ps1、bat 和 mods 里的模组
  · 你的 矿工配置.txt、服务器地址.txt、游戏目录.txt、启动模板.bat、bots 一律不动
  · 替换前会检查新脚本语法，有问题直接放弃；中途失败会自动回滚
  · 想只看版本不更新：powershell -File 更新工具.ps1 -CheckOnly
  · 想重装同一版：加 -Force
  · 网络被墙、只看得了网页看不了 API 时，在本目录放一个 github_token.txt（一行 token）即可

十五、仓库索引 /idx（1.11.0）
  走过箱子、木桶、潜影盒这类容器，模组自动记下里面有什么，存到 游戏目录\仓库索引.txt
  · /idx find 钻石      → 按距离远近告诉你哪口箱子有，多少个，离你几格
  · /idx scan           手动扫周围 11×11 区块（自动记录关掉时用）
  · /idx                看现在记了多少个容器
  · /idx auto on|off    自动记录开关
  · /idx clear          清空索引
  中文名能直接搜：钻石/铁/金/煤/红石/青金石/绿宝石/石英/铜/下界合金/木头/火把/镐…
  只读客户端已加载的区块，走远了没扫到是正常的。

十六、末影之眼定位要塞 /eye（1.11.0）
  不用 OP、不用种子：站在两个相隔较远的位置各扔一个末影之眼，模组自动记录飞行方向，
  然后 /eye calc 两条射线求交点 ≈ 要塞坐标。
  · 扔完等它飞出去，别马上去捡
  · 两次的位置隔远一点、角度差大一点，交点才准
  · /eye list 看记了几条；/eye clear 清空
  · 散布超过 ±300 格说明还不够准，再换个位置扔一次

十七、宏：录一遍点击，以后自动点（1.12.0）
  用法：打开要自动点的界面（箱子/商店/菜单/登录框）→ 按 F7 开始录 → 正常点按钮 → 再按 F7 结束
  · F7 录制/结束，自动保存到 游戏目录\宏\<界面标题>.txt
  · F8 手动回放当前界面的宏；回放中按 F8 停止
  · F9 开关“同一界面打开时自动回放”，默认开
  · 命令：/am macro（状态）、list、play 名字、del 名字、auto on|off
  说明：只录鼠标点击，不录打字；录制时点击会真实生效（等于你亲手演示一遍）。
  如果图形登录自动化和你录的宏抢点击，宏录制/回放期间会自动暂停图形登录，结束后恢复。

十八、回箱前指令/脚本：先办事，再回箱（1.13.0）
  达到回箱条件（攒够矿/到点/镐快坏/背包快满）后，先停下挖矿，按顺序发你配的指令，
  执行完再走去箱子存矿。适合回箱前先 /home、先 /kit、先给队友发消息。
  · 游戏里按 M → 翻到第 4 页「回箱前指令/脚本」
  · 指令用 | 分隔，按顺序发，不用写开头的 /：/home|/kit miner|/msg 队友 回箱
  · 脚本文件放 config 目录，默认 pre_deposit.txt，一行一条，也可 | 分隔，# 开头是注释
  · 指令间隔默认 10 tick（0.5 秒）；最后一条后默认等 20 tick 再回箱
  · 命令：/am predeposit（看）、on/off、add /home、del 序号、clear、script 文件名、delay tick、settle tick
  说明：脚本只发游戏指令，不会运行 .bat/.sh，不需要 UAC；会传送/换维度的指令建议把等待调大。

十九、指令生成器（浏览器打开，不用装东西）
  双击 multi\指令生成器.html，填参数就出命令，一键复制：
  · fill 填充（replace/destroy/hollow/keep/outline/strict，可只替换某种方块）
  · setblock 放方块、clone 复制、execute as/at/positioned
  · 坐标换算：站在原点，把绝对坐标换成 ~ 相对坐标
  支持 ~ 和 ^ 写法，写错会当场标红提醒；历史记录存在浏览器里。
