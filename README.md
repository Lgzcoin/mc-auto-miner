# 自动采矿多开助手（Minecraft Java 26.2 / Fabric）

一个给自己服务器用的挂机挖矿工具包：**客户端模组 + 一键多开启动器 + 实时控制台**。适合“多个小号同时挂机挖矿、按矿种分工、自动进服登录、挖满回箱存放”的场景。

> 只在**自己开的服务器**或**明确允许挂机**的服务器上使用；多开前先看清服务器规则。

## 它能做什么

**模组（autominer）**
- 自动进服（`--quickPlayMultiplayer` 直接连）、断线自动重连（间隔可调）
- 自动认证：按配置自动发 `/login`，误配 `/reg` 会自动转 `/login`
- 图形登录自动化：进服弹出容器/铁砧样式的登录菜单时，自动找「登录/进入/确认/密码」格点掉；铁砧界面会自动填密码提交
- 宏录制/回放：F7 录制键盘和鼠标（支持 Shift+F、Shift+左键），按界面标题保存；没有界面时录「全局」宏，F8 手动回放，F9 开关「同一界面打开时自动回放」
- 事件钩子：开始挖矿、回箱前、爆仓、镐快坏、定时、攒够、回箱后、挖完、停止，每个事件都能单独配宏、指令、脚本并开关（1.15.5）
- 行为准则弹窗自动同意
- 挖矿：接 Baritone 寻路，按矿种清单开挖；背包快满或到时间自动走到存矿箱存放，循环
- 开荒：进服 → 发你设的指令（如 `/home base`）→ 寻路到基地/矿点 → 到了才开挖
- 状态上报：每秒写一份 `autominer_status.txt`（画面、维度、坐标、血饱、在做什么、登录状态、心跳）

**启动器（multi）**
- 一个面板改名字、改矿种（支持中文矿名）、加号、删号、设基地与存矿箱、设进服指令、改重连间隔、按 `p` 改进入密码/登录指令
- 进入密码可自定义：输纯密码自动发 `/login 密码`，也可直接输 `/login`、`/l`、`/reg` 等完整指令；改完立即写入各号 `autominer.json`
- 每号独立游戏目录 `bots/<名字>`，改名目录一起改，删号软删除到 `_旧目录`
- 自动整理 mods：升级本模组、挪走冲突版本、缺 Fabric API / Baritone 时警告
- 名字强制 3–16 位英文/数字/下划线（服务器普遍不收中文名），中文名会自动换成 `MinerN`

**控制台**
- 状态表：名字 / 画面 / 维度 / 位置 / 血食 / 在干什么 / 登录 / 攒满 / 心跳
- 顶部一句话概览：`共 3 个号：2 个在挖矿，1 个没登录`
- 约 15 秒自动播一行「看板」，画面或状态变了才播
- `detail 名字` 看这个号的画面标题、最近聊天、最近动作（自动点登录成没成在这里能看到）
- `watch off` 关播报，`status` 重画表，`quit` 退出控制台（机器人继续跑）

## 环境要求

| 项 | 版本 |
| --- | --- |
| Minecraft | 26.2（Fabric） |
| Fabric Loader | ≥ 0.19.3 |
| Fabric API | 0.161.0+26.2 |

| Baritone | `baritone-api-fabric`（必须 api 版，standalone 精简版没有 `baritone.api`） |

## 安装

1. 把 `dist/autominer-1.15.6.jar` 放进 `.minecraft/mods/`
2. 放入对应 26.2 的 Fabric API 和 `baritone-api-fabric` jar
3. 把 `multi/` 整个文件夹放到桌面，双击 `启动多开.bat`

启动器会读 `multi/服务器地址.txt` 里的地址（`host:port`，填 `skip` = 只开游戏不进服），把每个号的数据放在 `.minecraft/bots/<名字>/`，并自动把模组复制/升级到 `.minecraft/mods/`。

详细操作见 `multi/启动方式说明.txt`。

最新多开包：`https://github.com/Lgzcoin/mc-auto-miner/releases/tag/v1.15.7`（`multi-launcher-1.15.7.zip`）。

## 从源码构建

```bash
# 需要 JDK 25 和 Gradle（本项目用 9.x 测试）
cd autominer
# 编译期需要 Baritone API：把 baritone-api-fabric 的 jar 放到 autominer/libs/baritone-api-1.19.0.jar
./gradlew build      # 或 gradle build
# 产物：build/libs/autominer-<版本>.jar
```

## 宏（按键 + 鼠标点击，1.15.2–1.15.4）

**有界面的宏**：先在游戏里打开要自动点的界面（箱子、商店、菜单、登录框），然后：

| 按键 | 作用 |
| --- | --- |
| F7 | 开始 / 结束录制（结束会自动保存） |
| F8 | 回放当前界面对应的宏；正在回放时按 F8 = 停止 |
| F9 | 开关「同一标题的界面打开时自动回放」 |

**全局宏：先按 Shift+F 打开服务器菜单**：

1. 站在游戏里，不要打开任何界面。
2. 按 F7 开始录制，提示「全局」。
3. 按 Shift+F 打开菜单，再点菜单里的按钮。
4. 按 F7 结束，保存为 `游戏目录/宏/全局.txt`。
5. 以后在游戏里按 F8，会先发 Shift+F，菜单打开后继续点。

1.15.2 起会同时录键盘和鼠标：`Shift+F`、`Ctrl+F`、`Alt+F` 这类组合键会带修饰键；`Shift+左键` 快速移动物品也不会退化成普通左键。F7/F8/F9 本身不会录进去。

1.15.3 起 F7/F8/F9 直接读 GLFW 原始按键，箱子/菜单界面打开时也能结束录制并保存，不再依赖 KeyMapping 派发。

1.15.4 起按键回放改用 Windows `SendInput`（JNA），不再依赖 AWT `Robot`。Minecraft 启动时会把 `java.awt.headless` 强制设为 `true`，所以旧版全局宏发 `Shift+F` 会报「Java Robot 不可用（系统禁止模拟按键）」；新版不初始化 AWT，只要游戏窗口在前台就能发键。


宏文件在 `游戏目录/宏/<界面标题>.txt`，可直接文本编辑；开关状态存 `游戏目录/宏配置.txt`。按键回放优先发真实系统按键，能触发服务器/模组的全局快捷键；系统不允许模拟按键时会退回界面事件。回放时游戏窗口要保持前台。

```
/am macro              看宏数量和开关状态
/am macro list         列出所有宏
/am macro rec          开始/结束录制（等同 F7）
/am macro play 名字     手动回放指定宏
/am macro stop         停止回放
/am macro del 名字      删除宏
/am macro auto on|off  自动回放开关
```

限制：只录「按下瞬间」，不录长按、拖拽、滚轮和连续打字；宏按界面标题匹配，标题相同但布局完全不同的界面可能点偏；录制时点击会真实生效，相当于你亲手演示一遍。

## 事件钩子（1.15.6）

每个关键节点都能挂自己的宏、游戏指令或指令脚本，并且能单独开关。按 **M** → 第 4 页「事件脚本」：

| 事件 | 什么时候执行 |
| --- | --- |
| 开始挖矿 | 第一次真正开始挖矿前（走到开荒点之后） |
| 回箱前 | 任何回箱条件命中后、走向箱子前 |
| 背包满/爆仓 | 背包空位不足触发回箱时 |
| 镐子快坏 | 镐子耐久低于阈值触发回箱时 |
| 定时回箱 | 定时回箱触发时 |
| 攒够矿物 | 指定矿物攒到数量触发回箱时 |
| 回箱后 | 存完矿/关箱后、继续挖矿前 |
| 挖完/找不到矿 | 附近没有可挖矿石、准备暂停时 |
| 停止挖矿 | 手动或自动停止时 |

点某一行的「编辑」会打开图形化动作面板：

- **勾选「宏」**：左侧用 `◀ ▶` 选 `宏` 目录里的宏，只跑宏；
- **勾选「指令」**：只发下面的游戏指令/脚本；
- **勾选「宏+指令」**：先跑宏，再发指令；
- 没勾选的类型不会执行，输入框也会变灰。
- **游戏指令**：多条用 `|` 分隔，按顺序发；不用写开头 `/`。例：`/home|/kit miner|/msg 队友 回箱`
- **脚本文件**：放在 `config` 目录的文本文件，一行一条，也可用 `|` 分隔，`#` 开头是注释；留空 = 不读
- **指令间隔**：每条之间等多少 tick，20 tick = 1 秒
- **执行完再等**：最后一条发完再等多少 tick 才继续下一步
- **开关**：每个事件独立开/关；没配内容的事件不会占用时间

回箱时的顺序是：**本次原因事件（爆仓/镐快坏/定时/攒够） → 回箱前 → 走向箱子 → 回箱后 → 继续挖矿**。如果指令会传送或换维度，建议把「执行完再等」调大，让服务器先传送完。

也可以用命令：

```text
/am hook                          列出所有事件
/am hook pre_deposit              看某个事件
/am hook pre_deposit on|off       开/关
/am hook pre_deposit add /home    追加一条
/am hook pre_deposit del 2        删除第 2 条
/am hook pre_deposit macro 回箱   先执行这个宏（off = 取消）
/am hook pre_deposit action macro|command|both   切换动作类型
/am hook pre_deposit clear        清空宏和指令
/am hook pre_deposit script xxx.txt
/am hook pre_deposit delay 10
/am hook pre_deposit settle 20
```

事件 key：`start`、`pre_deposit`、`full`、`low_pick`、`interval`、`threshold`、`post_deposit`、`mining_done`、`stop`。

说明：脚本是**游戏指令脚本**，只把每行发给服务器，不会运行 `.bat/.sh`，不需要 UAC。

## 已知限制

- 图形登录只能点**容器/铁砧**类界面；要求你在告示牌或书里手打字的界面需要人工点一次
- 同 IP 同时在线数量受服务器限制（常见是 2），第 3 个号要么换出口 IP，要么别同时开
- 自动挖矿依赖 Baritone 的寻路；远距离移动很慢，建议先进服传到基地附近
- 状态表的“心跳”是状态文件多少秒没更新：正常 0–1 秒，超过 15 秒变红说明这个客户端卡住或断线
